macOS Gatekeeper Revocation Bypass via Network-Layer Attacks

Hana Omori • August 2026 • Apple Ticket OE1107167498810 • CVE Request [UNVERIFIED — CAN-2026-2035261]

About this package: This repository documents a Gatekeeper revocation bypass in macOS Tahoe where DNS poisoning of OCSP responders causes trustd to fail open, allowing revoked-certificate apps to launch. Apple closed the bounty ticket stating "this is not security." No exploit code or weaponized tooling is included.
